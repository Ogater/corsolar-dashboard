# CorSolar

Демонстрационная панель мониторинга четырёх солнечных электростанций. Сейчас данные генерируются локально в диапазоне `0…1`; мощность каждой станции рассчитывается как `коэффициент × номинал`.

На экране показаны три уровня данных:

1. Отдельная генерация каждой СЭС.
2. Средняя генерация четырёх станций без коррекции и просадка при прохождении тучи.
3. Та же генерация после установки накопителя: красная линия — панели, жёлтая — вклад батареи, светлая пунктирная — итог.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```

## Данные

Панель запрашивает данные из `GET /api/demo-solar-battery/compare` при открытии и затем раз в минуту. Параметры запроса находятся в `src/api.js`.

В локальной разработке запросы `/api` проходят через Vite-прокси, потому что backend не разрешает CORS для `localhost`. Настройка:

```env
VITE_API_BASE_URL=
API_PROXY_TARGET=https://dev.monitoring.cor-int.com
```

Для production сервер фронтенда также должен проксировать `/api` на backend. Альтернатива — разрешить домен фронтенда в CORS и указать его адрес через `VITE_API_BASE_URL`.

Ответ за сутки может содержать 1440 минутных значений на каждую серию. Полный ответ обрабатывается приложением, а для отображения используется min/max-прореживание до 360 точек. Оно сохраняет пики и провалы, включая момент прохождения тучи.

При недоступном API интерфейс остаётся на демонстрационном наборе и показывает статус `API НЕДОСТУПНО · ДЕМО-РЕЖИМ`.
